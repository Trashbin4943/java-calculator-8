# java-calculator-precourse

## 기능 구현 목록

---

- 1. 문자 입력 창 생성

구분자와 양수로 구분된 문자열을 입력받는 **변수**를 선언하고, Scanner 로 입력받도록 합니다.

- 2. 입력 문자열 파싱 기능

입력받은 문자열을 **,와 :**을 기준으로 나누고, 분류된 숫자는 문자열 형식으로 실제 integer 형식으로 변환할 수 있도록 하는 자동 파싱 기능입니다.

- 3. 결과 도출 및 출력 기능

문자열을 파싱하여 추출한 숫자를 모두 더한 값을 결과로 도출하여 최종으로 출력합니다.
