# java-calculator-precourse

## 기능 구현 목록

---

- F1. 문자 입력 창 생성

구분자와 양수로 구분된 문자열을 입력받는 **변수**를 선언하고, Scanner 로 입력받도록 합니다.

- F2. 사용자 커스텀 분류 메트릭 유무 체크 및 구분자 선택 기능

사용자가 커스텀으로 선택한 텍스트 분류 메트릭의 존재 여부를 파악하기 위해 문장을 1차 파싱하여 구분자를 선택하는 기능입니다.

- F3. 선택 구분자 기준 텍스트 내 연산 숫자 추출 기능

F2에서 선택한 구분자를 기준으로 텍스트를 2차 파싱하여 문장 내 구분자로 나뉜 숫자들을 추출하여 리스트로 저장합니다.

- F4. 해당 숫자들의 합을 최종 정답으로 출력

F3에서 추출한 숫자들의 리스트의 sum 값을 출력하여 최종 정답을 내는 기능입니다.
